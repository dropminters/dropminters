What a mint call does

  • freeMint(uint256 nonce) — payable; msg.value must be at least miningFee (default 0.0003 BNB). Mines PoW against on-chain challenge / difficultyTarget. 1 free mint per wallet. Overpay is refunded.
  • paidMint(uint256 quantity) — payable; msg.value = mintPrice * quantity (default 0.003 BNB each, max 2 / wallet). Paid phase starts off until owner enables it.
  • Both free and paid mint require a SPACE ID Agent ID NFT balance and an EOA caller (msg.sender == tx.origin).

What it never asks for

The mint path does not call or require approve, permit, setApprovalForAll, or any other token allowance. Do not sign any allowance for this mint.

Owner-only functions (from source)

Only the Ownable owner (0xF159…4Bd87) can call:

  • ownerMint(to, quantity) — reserve ≤100, bypasses Agent gate
  • setFreeMintActive / setPaidMintActive
  • setDifficulty / setMiningFee / setMintPrice
  • setAgentIdNft / setAgentGateEnabled
  • setUnrevealedURI / setBaseURI / reveal
  • bumpChallenge / setDefaultRoyalty / withdraw
  • Ownable: transferOwnership / renounceOwnership
